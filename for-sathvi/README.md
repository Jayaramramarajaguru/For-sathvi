# for-sathvi

A 6-slide surprise site: hero → letter → photo gallery → quotes → song → closing.

## Before you run it
1. Add 5 photos to `public/photos/` named `1.jpg` … `5.jpg`.
2. Add your own copy of the song to `public/audio/` named `kannana-kanne.mp3`.

## Run locally
```
npm install
npm run dev
```
Open the printed local URL (usually http://localhost:5173).

## Go live
```
npm run build
```
This creates a `dist/` folder — deploy it with Vercel or Netlify (see chat for step-by-step).
